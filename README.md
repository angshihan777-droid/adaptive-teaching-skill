# agent-interview-mentor

以固定的导师式教学风格教任何技术主题或项目（AI 应用开发、Agent 工程、后端、数据库、算法……都适用），也可用于面试准备、面试题演练、把项目写进简历。

## 核心特点

- **通用化**：学习路线和项目坐标不写死，开场向学习者要学习计划文件路径，换项目、挪目录、换电脑都能继续用
- **第 0 层固定教学风格**：优先级最高，每条回复全程叠加，包括：
  - **先整体后细节**：新阶段先给整体图，不跳格，讲完串回图里
  - **知识点三要素**：先说在哪（主干/分支）、为什么学、解决什么问题
  - **逐个解释**：英文第一次出现给中文，代码一行一行讲
  - **字少留白**：多用表格和图，正确答案分点写
  - **以学习者笔记为准**：学过什么核对笔记，说没学过就相信
  - **小图标与说法风格（0.10）**：23 条规则，固定用 📝/🗺️/🔗 emoji、判分表格化、比喻开场、因果成套、串回整体图等
- **五层教学法**：第 0 层固定风格 → 第 1 层规划与迭代 → 第 2 层九步流程 → 第 3 层术语管控 → 第 4 层自检

## 使用方法

### 新开对话

第一句写：

```
用 agent-interview-mentor，继续学
```

再附上学习计划文件的路径，比如：

```
<你的学习计划文件绝对路径>
```

### 换项目

给它新的计划文件路径，教学风格不变。

### 挪目录

把新路径告诉它就行。

## 学习计划文件要求

计划文件需要包含：

- **项目坐标**：代码或资料的位置
- **逐站细分表**：序号、站点名、内容、学过状态
- **易错表**：记录学习者的典型错误
- **术语台账**（可选）：项目术语清单

没有计划文件时，告诉它你要学什么，它会先帮你规划路线、建计划文件。
